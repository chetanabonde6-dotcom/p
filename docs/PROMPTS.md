Use the same project/chat. Give ChatGPT current code if it cannot access this repository.

## Start
I am Chetana, a complete beginner. Read our exact problem statement: [attach/paste]. Our deadline is [time and timezone]. Use our current code and AGENTS.md. Choose the strongest small complete demo flow and implement the first working frontend. Give me a preview when available and one simple next action.

## Improve
Here is a screenshot of our actual app. Improve layout, typography, spacing, hierarchy, mobile usability, and the main action to suit [target user]. Implement focused changes and preserve the working flow.

## Fix
After I [action], I expected [result] but got [actual result]. Here is the screenshot or exact error. Inspect the current code, fix the cause, verify the affected behavior, and explain the next action simply.

## Connect
Here are the agreed API base URL, methods, endpoints, request/response examples, errors, and authentication mechanism. Connect them through the data layer. Verify success and failure states. Keep demo mode explicit.

## Publish
Publish our current frontend using available hosting and verify the link. Tell me whether it is public. If publishing is unavailable, give me the complete source and exact deployment steps for our stack.

## Thirty minutes left
Freeze new features. Fix demo-blocking issues, check the main flow and phone layout, prepare a runnable backup, and give me a two-minute demo script. Clearly list real versus mock features and remaining limits.

## Explain
Explain our actual screens, main components, and data flow in simple English. Help me honestly explain my frontend contribution and practise five likely judge questions.

## Continue
Read the latest PROJECT_BRIEF checkpoint and current repository. Continue the next priority task without restarting our design or changing the agreed framework.
